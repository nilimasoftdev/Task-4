# Task 4: CSS Units, Box Model & Fonts

A simple HTML and CSS project demonstrating the use of CSS units, box sizing, spacing, image styling, and button customization.

## Overview

This project contains an image display section with a styled button. The layout is created using CSS viewport units and the CSS box model without using Flexbox or positioning.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive layout using `vw` and `vh`
- CSS Box Model
- `box-sizing: border-box`
- Image styling with `object-fit: cover`
- Gradient button background
- Custom font styling
- Button hover cursor
- External CSS stylesheet
- No Flexbox
- No absolute or relative positioning
- No `overflow: hidden`
